# متجر وكيل جوجل — Next.js + Postgres

مشروع متجر رقمي كامل (واجهة عميل + لوحة تحكم + قاعدة بيانات حقيقية) لبيع شحن الألعاب والتطبيقات، مبني بـ Next.js 14 (App Router) و Prisma و Postgres.

## ما يعمل فعليًا الآن
- كل بيانات المتجر (منتجات، باقات، تصنيفات، وسائل دفع، طلبات، إعدادات) محفوظة في **قاعدة بيانات Postgres حقيقية** عبر Prisma — لا يوجد أي اعتماد على localStorage أو React state مؤقت.
- نظام تسعير صنعاء/الجنوب: `southPrice = sanaaPrice × southMultiplier` مع هامش ربح عام + هامش ربح إضافي لكل تصنيف (تصنيف "تطبيقات وخدمات" مضبوط افتراضيًا على 20%) + تقريب.
- زر "إعادة حساب أسعار الجنوب" يأخذ نسخة احتياطية تلقائيًا في جدول `PriceBackup` قبل أي تحديث جماعي.
- عند إنشاء الطلب: يختار العميل وسيلة الدفع، وإن كانت الوسيلة تتطلب حوالة، يظهر له حقل "رقم الحوالة" إجباريًا قبل إرسال الطلب.
- رسالة واتساب تلقائية عند تأكيد الطلب.
- حالات الحفظ (جاري الحفظ / تم الحفظ / فشل الحفظ) في كل نماذج لوحة التحكم.

## ⚠️ أشياء مهمة صادقة قبل الإطلاق الفعلي
1. **الحماية بسيطة جدًا حاليًا**: كلمة مرور واحدة عبر `ADMIN_PASSWORD` تُرسَل كترويسة `x-admin-key` مع كل طلب — هذا أفضل من عدم وجود حماية إطلاقًا، لكنه **ليس نظام تسجيل دخول حقيقي بجلسات وصلاحيات**. قبل الإطلاق الفعلي أنصح بإضافة NextAuth أو مشابه.
2. **الصور تُدخَل كروابط URL فقط** — لا يوجد رفع ملفات (upload) داخل هذا المشروع بعد. إذا احتجت رفع صور مباشرة، يلزم ربط خدمة تخزين (مثل Vercel Blob أو Cloudinary).
3. **بيانات كلاش رويال و Dream League Soccer لم تُدرج بعد** لأن المعلومات المرسلة كانت ناقصة/متضاربة (كلاش رويال بسعر منطقة واحدة فقط، وDLS بعملة مختلفة لعدن) — أضفها لاحقًا من لوحة التحكم بعد توضيح الأسعار.
4. **رقم واتساب الطلبات** قابل للتعديل من "إعدادات الأسعار" في لوحة التحكم — تأكد من ضبطه على الرقم الصحيح.
5. **كلمة مرور حساب العميل (لتطبيقات "بريد + كلمة مرور") تُخزَّن كنص عادي في قاعدة البيانات** — هذا شائع في متاجر الشحن لكنه خطر أمني حقيقي إذا تسربت قاعدة البيانات. قبل الإطلاق الفعلي يُفضَّل تشفيرها (encryption at rest) أو حذفها تلقائيًا من قاعدة البيانات بعد تنفيذ الطلب بفترة قصيرة بدل الاحتفاظ بها إلى الأبد.

## خطوات النشر على Vercel (تقريبًا 5-10 دقائق)

### 1) إنشاء قاعدة بيانات Postgres مجانية (Neon)
1. افتح https://neon.tech وأنشئ حسابًا مجانيًا.
2. أنشئ مشروعًا جديدًا (New Project).
3. انسخ رابط الاتصال (Connection String) — يبدأ بـ `postgresql://...`.

### 2) رفع الكود إلى GitHub
```bash
cd wakeel-store
git init
git add .
git commit -m "أول نسخة من متجر وكيل جوجل"
```
ثم أنشئ مستودعًا جديدًا على GitHub وارفع الكود إليه (`git remote add origin ...` ثم `git push`).

### 3) الربط مع Vercel
1. افتح https://vercel.com وسجّل دخول بحساب GitHub.
2. اضغط "Add New Project" واختر المستودع الذي رفعته.
3. في خطوة Environment Variables أضف:
   - `DATABASE_URL` = رابط Neon الذي نسخته
   - `ADMIN_PASSWORD` = كلمة مرور قوية من اختيارك (غيّرها عن admin123)
4. اضغط Deploy.

### 4) تجهيز قاعدة البيانات وزرع البيانات الأولية
بعد أول Deploy، من جهازك محليًا (أو عبر Vercel CLI):
```bash
npm install
npx dotenv -e .env.local -- npx prisma migrate deploy
npx dotenv -e .env.local -- npm run seed
```
(أنشئ ملف `.env.local` يحتوي على نفس `DATABASE_URL` المستخدم في Vercel)

### 5) النتيجة
Vercel سيعطيك رابطًا عامًا مباشرة بالشكل:
`https://اسم-مشروعك.vercel.app`
هذا الرابط يعمل من أي متصفح وأي جوال، ويمكنك ربط دومين خاص بك لاحقًا من إعدادات Vercel.

## التشغيل محليًا للتجربة
```bash
npm install
cp .env.example .env
# عدّل DATABASE_URL في .env برابط Postgres حقيقي (Neon مثلاً حتى محليًا)
npx prisma migrate dev --name init
npm run seed
npm run dev
```
افتح http://localhost:3000 للمتجر، و http://localhost:3000/admin للوحة التحكم.
